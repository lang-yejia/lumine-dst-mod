# 旅行手册书页规范

## 视觉与交互

| 项目 | 实施规范 |
| --- | --- |
| 纸面 | DST 剪贴簿的 `scrap_square.tex` 作书页，暖棕色封边模拟皮封。复用三种 `scrap2` 纸片做卷封、收藏卡和索引底衬。纸页接缝、图片装裱和手记侧边线划分内容。 |
| 字体 | 使用原版 `CHATFONT`。书名和章节标题 30–33，目录标题 22–24，阅读正文 17–22，路径和状态 14–17。正文左对齐，卡片导语最多两行。 |
| 操作 | 金色原版按钮用于解锁技能和合上手册。四卷采用书签，选中时以原版描边突出。筛选和翻页使用浅色背景，返回和关联章节使用轻量文字链接，悬停时显露底色。 |
| 状态 | 深绿表示完成，赤褐表示待交证物或记录中，褐灰用于待探索。待收录物件压低亮度，并保留对应的状态文字。 |
| 页面 | 同一个 Screen 下替换内容区。顶部是封面和四卷，卷内先选题材，再按解锁方式筛选。目录每页两列两行，点击卡片打开全页。关联章在同屏打开，返回保留来源卷、筛选和页码。 |
| 图片 | 首页营火、章内生物和目录缩略图沿用原版图鉴的原始比例。封面纸框约 476×272，普通阅读页约 440×198。武器、护甲和圣遗物使用对应的装备图标。 |
| 适配 | 1104×720 逻辑书板按屏幕等比居中缩放。书签和页脚绘制在主内容之上。窄窗口、超宽屏和高 HUD 缩放需要实机检查。 |

首页分别显示 30 章的图鉴进度、20 项旧见闻进度和 15 件圣遗物进度。已开放的百科章节可直接计入收录。套装首件可开启套装阅读，四季页的三项见闻完成后计为一个已收录章节。最近发现来自当前角色会话。倒计时在封面和派蒙专题更新对应文本。

武器采用四阶横向路线，头甲与身甲各占一行。各阶段从现有重铸数据读取原版装备与消耗，从联机状态读取「待体验」「可记录」「已记录」。点击节点查看其条件。圣遗物总览提供三套入口，每套展示五件状态、部位效果、套装能力与定向状态。冬、春、夏沿用各自的见闻编号和奖励。

正式版的配置面板与手册均隐藏完成见闻的测试入口。本地开发可在 DST 的 `dev` 分支将 `modinfo.lua` 的 `journey_dev_tools` 改为 `true`。服务端测试 RPC 使用相同的分支和开关限制。

## 设计参考

- 纸页、卡片及书签取自本机 DST 的原版剪贴簿 atlas。原版剪贴簿提供饥荒风格基准。 [Klei 更新说明](https://kleiforums.com/game-updates/dst_switch/180-r2081/)
- 将「知道有这一章」与「已解锁手记」分开，借鉴发现条目与逐步开启笔记的节奏。 [Team Cherry 的猎人日志介绍](https://www.teamcherry.com.au/blog/filling-out-the-hunters-journal-interview-and-game-informer)
- 卷、主题目录、正文分层，并在正文提供关联阅读。参考任务记录与资料分类各自有入口的组织方式。 [《巫师 3》官方 PC 手册](https://cdn-l-thewitcher.cdprojektred.com/media/TW3/Pdf/Manuals/PC/The_Witcher_3_Wild_Hunt_Game_Manual_PC_GB.pdf)
- 阶段节点间的连线表现先后依赖，具体材料和条件在选中节点下方查看。参考科技树和配方之间的定位关系。 [《Craft The World》开发者更新](https://store.steampowered.com/news/posts/?appids=248390&enddate=1592461709&feed=steam_community_announcements)
- 圣遗物固定五部位位置，保留未收录槽位和已收录的可读状态。 [《星露谷物语》收藏页](https://stardewvalleywiki.com/Collections)

## 原版图鉴和首领探索指南

第六阶段使用 DST 762172 的图鉴资源。封面与巨鹿旧横幅已退出运行时资源表。生物、建筑和地标使用 Scrapbook 纹理。道具使用原版物品图标，模组专用内容沿用项目的图标和动画。章节图元及首领分类见[原版图片映射](journey-native-art.md)。

首领指南在封面和饥荒世界卷可直接打开。旧首领见闻章的右页有对应攻略入口，即使证物尚未交付也能查看。两条主线使用同一书页，按阶段显示独立分支和合流后的步骤。选择步骤后右侧展示操作、数量和材料，返回会恢复上一个指南页的位置。攻略阅读不计入 30 章收录、见闻奖励或存档进度。

「查找手册」固定在书签右侧。搜索跨四卷章节、首领详情和两条路线的步骤，支持材料名和部分常用别名。搜索结果直接打开对应页或节点。首领页左栏集中展示地点、触发与准备，右栏展示机制、战利品与后续探索，底部排列相关道具。右上角的金色返回按钮显示目的地，保留来源页的搜索词、页码、卷内筛选、路线节点及章节内选择。Esc 与返回按钮共用同一套历史。

## 游戏内验收

- 用 16:9、窄窗口、超宽屏及两种 HUD 缩放打开首页，确认页脚、侧边卡片和长中文标题完整。
- 浏览四卷、组合筛选、翻页、点关联章再返回，检查书签、筛选状态与原目录位置。键鼠和手柄分别验收。
- 在派蒙接受证物、计时、背包满格和返还后打开手册，确认最近发现、秒数及待返还数量。联机客户端复测。
- 检查装备成长路线、五部位卡、四季各页、锁定正文和现有技能入口。对照封面、原版生物章和模组专用章的图像比例。
- 检查三祭坛和三祭品分支、指南详情与路线互跳，以及返回时节点和页码是否正确。
