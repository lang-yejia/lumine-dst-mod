# 合成台美术与升级路线

源图由内置 imagegen 生成，为参考《原神》合成台的《饥荒联机版》手绘风格建筑素材，并非官方贴图。提示词核心：三分之四视角、石质八角台座、炼金刻线、黄铜镶边、青色晶体、透明背景；亮起帧只加强晶体及刻线的青色发光，保留建筑形状。`tools/build-alchemy-table-art.py` 将两张源图制作成 384×384 的 Spriter 帧与图标。游戏内 `idle` 保持低亮，玩家靠近时播放 `proximity_loop` 持续脉动，制作时播放 `use`，离开后恢复低亮。

| 阶段 | 合成配方 | 武器伤害 |
| --- | --- | ---: |
| 无锋剑 | 树枝×2、燧石×4、猪皮×2 | 34 |
| 黎明神剑 | 无锋剑×1、蓝宝石×2、金块×4 | 42 |
| 试作斩岩 | 黎明神剑×1、齿轮×2、石砖×4、月石×2 | 51 |
| 风鹰剑 | 试作斩岩×1、铥矿×4、绿宝石×1、噩梦燃料×4 | 68 |

无锋剑与合成台的建造配方在原版角色物品制作栏中。合成台需要石砖×4、木板×2、金块×4、蓝宝石×1，并需要科学机器解锁。后三把剑只能由莹在合成台旁逐级合成，旧剑作为材料被消耗。当前武器只有普通伤害，没有额外技能或耐久机制。
