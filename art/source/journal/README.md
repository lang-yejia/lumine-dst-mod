# 旅行手册与成长系统

美术由内置 imagegen 生成。提示词：单本合上的旅行手册，米色旧皮封面、深蓝书脊、金色罗盘星纹、青色书签；《饥荒联机版》手绘墨线风格，透明背景，缩小后可辨认。`tools/build-journal-art.py` 生成物品帧和背包图标。手册界面中的里程碑和技能图片使用游戏原版物品图标。

手册随新角色初始物品发放；已有存档可在角色物品栏用莎草纸×1和羽毛笔×1制作。从背包右键手册选择“打开手册”，可分页查看里程碑，在“技能”页花见闻解锁能力。进度、见闻和技能储存在莹的角色组件中，死亡后保留。旧版手册存档会保留已完成的前五项目标。

里程碑覆盖第一夜、冬季、春季、夏季、洞穴、乘船、月岛岩地，以及击败巨鹿、龙蝇、远古守护者和天体英雄。每项只奖励一次见闻。首领死亡时，附近 24 单位内存活的莹都能记录该目标，方便联机协作。

技能有三支，每支两项，后一项需要先解锁前一项：

| 分支 | 第一项 | 第二项 |
| --- | --- | --- |
| 求生 | 旅行口粮：饥饿消耗 -10%，花费 2 | 旅途防护：受到伤害 -6%，花费 4 |
| 远行 | 轻盈步伐：陆上移速 +7%，花费 3 | 风雨同行：额外防雨 20%，花费 4 |
| 剑术 | 熟练剑士：模组剑伤害 +8%，花费 3 | 战后振奋：击败生命上限至少 100 的敌人后恢复 4 理智，冷却 20 秒，花费 5 |

技能数值在服务端生效，解锁请求由服务端验证。武器升级与合成台仍沿用现有路线，技能不会额外提高其他模组武器的伤害。
